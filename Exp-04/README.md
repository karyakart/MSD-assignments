## 🎯 Aim / Objective

---

## 📑 Theoretical Background

**Material UI (MUI)** is one of the most popular React component libraries, implementing Google's Material Design system. It provides comprehensive, accessible, and customizable components that streamline frontend development.

### Demonstrated MUI Components:

#### Set A (Core Showcase):
1. **Accordion & AccordionDetails:** Collapsible content panels.
2. **Alert:** Status indicators (warning, info, success, error).
3. **Autocomplete:** Dynamic search/filter input with dropdown suggestions.
4. **Breadcrumbs:** Navigational hierarchy display.
5. **Chip:** Compact elements representing attributes, entities, or tags.
6. **Divider:** Visual horizontal or vertical separator.
7. **Floating Action Button (FAB):** Circular action trigger with icons.
8. **LinearProgress:** Horizontal progress bar for indeterminate or determinate states.
9. **Menu & MenuItem:** Contextual dropdown action list.
10. **Pagination:** Navigation control across paginated datasets.
11. **Popover:** Contextual floating overlay anchored to an element.
12. **Rating:** Interactive star rating component.
13. **Skeleton:** Placeholder preview loading state.
14. **SpeedDial:** Floating action button expanding into a cluster of actions.

#### Set B (Extended Demo in `mui-demo2/`):
15. **Slider:** Continuous or discrete range selector.
16. **Switch:** Binary toggle switch (ON/OFF).
17. **Avatar:** Visual identity display (letters, icons, and image avatars).
18. **Badge:** Small numerical notification indicator.
19. **CircularProgress:** Circular loading spinner.
20. **Drawer:** Side navigation panel with slide animation.
21. **Tabs & Tab:** Organized tabbed navigation.
22. **Tooltip:** Informative hover popup.

## 🚀 How to Run Locally

1. Navigate to this folder:
   ```bash
   cd Exp-04-MUI-Components
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm start
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

To run the extended demo:
```bash
cd Exp-04-MUI-Components/mui-demo2
npm install
npm start
```
